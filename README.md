# File Analyzer

A lightweight CLI tool for analyzing files, metadata, formats, and basic file statistics.

## Features

- File size and type detection
- MIME type detection
- File metadata inspection
- SHA-256 hash calculation
- Basic text/binary detection
- Human-readable output
- Command-line interface

## Usage

```bash
python3 file_analyzer.py <file>
```

Example:

```bash
python3 file_analyzer.py example.txt
```

## Requirements

- Python 3.10+
- Linux, macOS, or Windows

The project uses only Python's standard library.
